## Agent skills

### Issue tracker
- Default tracker: GitHub Issues for `justbill2020/Lambchop`.
- Use the `gh` CLI from this repository; prefer `gh issue ...` commands over ad hoc browser or dashboard mutations.
- See `docs/agents/issue-tracker.md` for create/read/list/comment/label conventions.
- Every triage-created issue or issue comment must begin with `> *This was generated by AI during triage.*`

### Triage labels
- Use the canonical triage roles in `docs/agents/triage-labels.md`.
- If a required label is missing from GitHub, record the blocker instead of silently inventing a different state label.

### Domain docs
- Read `docs/agents/domain.md` before using issue, triage, PRD, or autonomous-workflow skills.
- Lambchop is self-hosted: the active automation may run inside this repo while changing the automation system that manages it.
